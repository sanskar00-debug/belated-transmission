# 🛰️ Belated Transmission: A Special Birthday Delivery

A lightweight, interactive micro-website built as a belated birthday surprise for an incredible friend.

---

## ✨ Features

- **Interactive Decryption Lock:** A playful sci-fi prompt requiring user activation to reveal the message.
- **Confetti Physics:** Powered by `canvas-confetti` for celebratory visuals.
- **Responsive & Lightweight:** Built with zero-dependency semantic HTML5, modern CSS, and vanilla JavaScript.

---

## 🛠️ Built With

- **HTML5 & Modern CSS3** (Flexbox, CSS Variables, Glassmorphism touches)
- **Vanilla JavaScript** (DOM manipulation, event handling)
- **Canvas-Confetti** (Dynamic particle effects)
- **GitHub Pages** (Continuous deployment)
